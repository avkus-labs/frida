# Проверка безопасности avkus-labs/frida

Проверенная ревизия — [e341cab0](https://github.com/avkus-labs/frida/tree/e341cab067f62e10adca9c8246d00dc89bbb6df9). Встроенный DEX воспроизведён из официальной Google BillingClient 5.2.1. Архив сервера Frida и распакованный бинарник на проверенном компьютере совпали с релизом 17.9.1 для Android x86_64. Основные риски связаны с запуском непроверенных файлов на Android с правами root и чтением данных покупок. Для основного телефона с личным Google-аккаунтом такой запуск рискован.

## Что проверено

| Объект | Метод и результат |
|---|---|
| Исходники | Статически проверены main.py, frida.js, module_b64.py и requirements.txt. |
| module_521.apk | Переданный образец побайтно совпал с результатом декодирования Base64 из module_b64.py. В ZIP одна запись — classes.dex. |
| classes.dex | Из classes.jar официального AAR собран DEX компилятором D8 8.6.2-dev в режиме debug с min-api 26. Совпали все 259 208 байт, включая инструкции методов. В JADX видны ожидаемые ветки com.android.billingclient и com.google.android.gms.internal.play_billing. |
| Сервер Frida | Для архива сопоставлены релизный SHA-256, объект Git и хеш локального файла на Windows. SHA-256 распакованного файла на Windows также совпал с эталоном. |
| Android | Хеши файлов на устройстве не предоставлены. Работа скриптов на телефоне, трафик и платёжные операции в рамках аудита не проверялись. |

Эталонные источники — [Google Maven, BillingClient 5.2.1](https://dl.google.com/dl/android/maven2/com/android/billingclient/billing/5.2.1/billing-5.2.1.aar) и [релиз Frida 17.9.1](https://github.com/frida/frida/releases/tag/17.9.1).

## Как работает проект

1. На компьютере Python находит ADB, выбирает устройство, проверяет root, наличие Google One и аккаунта Google. При необходимости устанавливает инструменты Frida.
2. На Android скрипт проверяет наличие модуля, подготавливает сервер и при необходимости запускает его с root.
3. Скрипт перезапускает Google One, подключается к процессу и загружает JavaScript. Через BillingClient код запрашивает предложения Google Play и для выбранного предложения открывает экран оформления. В просмотренном JavaScript автоматического подтверждения подписки не обнаружено.
4. При замене подписки скрипт ищет токен предыдущей покупки. При выходе Python выгружает JavaScript и отсоединяется от процесса. Сервер и скопированные файлы могут остаться на устройстве.

## Находки в скриптах

Строки относятся к ревизии e341cab0.

| Приоритет | Где | Поведение и последствия |
|---|---|---|

В проверенных Python- и JavaScript-файлах явной отправки токенов на сторонний HTTP-адрес не обнаружено. Фактический сетевой трафик устройства не записывался.

## Как проверить файлы на Android

Для проверки достаточно ADB и доступа на чтение. Запустите в PowerShell `adb devices -l`, найдите нужный телефон и укажите его серийный номер. Команда читает файлы без их запуска.

```powershell
adb devices -l
$serial = 'СЕРИЙНЫЙ_НОМЕР'
adb -s $serial shell sha256sum /data/local/tmp/frida-server /data/local/tmp/module_521.apk
```

| Файл | Размер, байт | Эталонный SHA-256 |
|---|---:|---|
| frida-server-17.9.1-android-x86_64.xz | 31 614 892 | `f5f1205ffb3cb145de9264a8c6aa7aa8724a2e33df319d476f2ef67cac453c5f` |
| frida-server после распаковки | 110 787 848 | `fd677533f1215654308e06db3c34905ed6a456a39343696b2f38ead09415884d` |
| module_521.apk | 105 971 | `38a1cd132f10b31c3f4ec85d341764c702148175e2db7e480a288468b39b7b74` |
| classes.dex внутри модуля | 259 208 | `7ad0f879719e47d52375a859df41735d8b3bc06d3836074e0581409bec874f89` |

Для серверного файла на Android используйте строку распакованного бинарника соответствующей версии и архитектуры. При совпадении обоих хешей текущие файлы на устройстве соответствуют проверенным образцам. Это не устанавливает, какой код исполнялся до проверки. При расхождении сохраните копию для отдельного анализа до запуска.
