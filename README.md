# Выбор тарифа Google One через Frida

На Android-устройстве с root-доступом скрипт подключается к процессу Google One и открывает в Google Play экран оформления выбранного тарифа. **Подписку подтверждает сам пользователь.**

Для работы нужны root-доступ, установленное приложение Google One и вход в аккаунт Google на устройстве. Скрипт `main.py` настраивает подключение через ADB и при необходимости копирует на устройство `frida-server` и `module_521.apk`.

## Запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

```powershell
python main.py --plan helium_1m          # Оформить новую подписку
python main.py --renew --plan pro_6m     # Продлить существующую подписку
python main.py --serial emulator-5560    # Явно выбрать устройство
```

## Меню

Тарифы разделены на четыре группы — **Plus**, **Pro**, **Ultra 5x** и **Ultra 20x**. Список берётся из `PLANS` в файле `frida.js`.

| Ввод | Действие |
|---|---|
| Номер или название тарифа | Открыть экран оформления в Google Play |
| `s` | Переключиться между новой покупкой и продлением (`STACK`) |
| `a` | Добавить тариф YouTube |
| `e` | Повторить проверку и подготовку окружения |
| `g` | Перезапустить Google One и заново загрузить скрипт в процесс приложения |
| `q` | Выйти |

## Новая подписка и продление

В `frida.js` переменная `STACK` определяет режим работы:

```js
var STACK = false; // Новая подписка
var STACK = true;  // Продление существующей подписки Google One (ReplacementMode = 5)
```

По умолчанию выбрана новая подписка. Для продления используется клавиша `s` в меню или параметр `--renew` в командной строке. В текущем аккаунте должна быть действующая подписка, для которой доступно продление.

## Что скрипт делает автоматически

1. Ищет ADB в `PATH`, Android SDK и каталоге установки MuMu.
2. Если устройств нет, перезапускает сервер ADB и пробует подключиться к стандартным портам эмуляторов MuMu, LDPlayer и Nox.
3. Если одно устройство обнаружено несколько раз, объединяет записи. При выборе отдаёт предпочтение устройству с root-доступом, установленным Google One и выполненным входом в аккаунт Google.
4. Если на компьютере отсутствует Frida, устанавливает `frida-tools` через pip.
5. Если на устройстве отсутствует `/data/local/tmp/module_521.apk`, декодирует модуль из `module_b64.py` и копирует его через ADB.
6. Если на устройстве отсутствует `frida-server` или его версия отличается от версии Frida на компьютере, берёт сервер из `assets/` либо загружает с GitHub, затем запускает его на устройстве.

## Файлы проекта

| Файл или каталог | Назначение |
|---|---|
| `main.py` | Точка входа. Подготавливает окружение, выводит меню и загружает скрипт в процесс приложения |
| `frida.js` | Скрипт Frida с таблицей тарифов и кодом для работы с BillingClient |
| `module_b64.py` | DEX-модуль BillingClient 5.2.1 в кодировке Base64 |
| `requirements.txt` | Зависимости Python |
| `assets/` | Локальный кеш файлов `frida-server` |

На устройстве используются следующие пути:

- `/data/local/tmp/module_521.apk`
- `/data/local/tmp/frida-server`
