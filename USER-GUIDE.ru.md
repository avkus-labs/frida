# Windows и Android — инструкция для первого подключения

## 1. Разберитесь, какой файл у вас на руках

**Если вы скачали `module_521.apk`, вручную загружать его на телефон не требуется.** Оставьте скачанную копию на компьютере. Внутри файла находится библиотека платёжного клиента. Значка приложения после нажатия на этот файл не появится.

В проекте уже есть своя копия модуля в файле `module_b64.py`. Место, которое исходный код отводит ему на Android, — `/data/local/tmp/module_521.apk`. Это служебный путь. Папка `assets` на Windows предназначена для файлов сервера Frida. Само приложение **Google One** устанавливается из Google Play.

## 2. Подготовьте компьютер

Для подключения телефона к Windows нужна утилита **ADB**. Она входит в бесплатный набор **Android SDK Platform-Tools**. Для этого шага хватит самого набора.

1. Откройте [страницу Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) и выберите загрузку для Windows.
2. Откройте скачанный ZIP в Проводнике и нажмите **Извлечь всё**. Откройте распакованную папку `platform-tools`, в которой виден файл `adb.exe`.
3. Щёлкните по адресной строке этой папки, введите `powershell` и нажмите **Enter**. В открывшемся окне выполните:

   ```powershell
   .\adb.exe version
   ```

   Должна появиться строка с версией Android Debug Bridge. Оставьте окно открытым для следующего шага.

## 3. Подключите телефон по USB

1. На телефоне откройте **Настройки → О телефоне** и семь раз нажмите **Номер сборки**. На некоторых моделях он находится в разделе **Сведения о ПО**. Если телефон попросит, введите свой PIN на самом телефоне.
2. Найдите через поиск настроек **Для разработчиков**, откройте раздел и включите **Отладку по USB**.
3. Подключите разблокированный телефон кабелем USB с передачей данных к своему компьютеру.
4. В том же окне PowerShell выполните:

   ```powershell
   .\adb.exe devices -l
   ```

5. На телефоне подтвердите запрос **Разрешить отладку по USB?** для своего компьютера. Выполните команду ещё раз. Серийный номер и слово `device` рядом с ним означают, что подключение готово.

| Что появилось в PowerShell | Что делать |
|---|---|
| Только строка `List of devices attached` | Попробуйте другой кабель с передачей данных и USB-порт. Если список по-прежнему пуст, установите [драйвер производителя для Windows](https://developer.android.com/studio/run/oem-usb). |
| `unauthorized` | Разблокируйте экран и подтвердите запрос на телефоне. Если запрос исчез, переподключите кабель. |
| Ошибка, что `.\adb.exe` не найден | Откройте PowerShell из распакованной папки, где лежит `adb.exe`, как в шаге 2. |

После работы отключите кабель. При желании выключите **Отладку по USB** в настройках телефона.

## 4. Если вы хотите выбрать тариф Google One

Это можно сделать целиком на телефоне, пропустив подготовку компьютера и подключение USB.

1. Откройте **Google Play**, найдите **Google One** от **Google LLC** и установите или откройте приложение.
2. Нажмите на изображение профиля и убедитесь, что выбран нужный аккаунт.
3. Для первой подписки откройте раздел с предложением перейти на платный тариф. Для действующей подписки откройте настройки Google One и выберите изменение плана. Доступные предложения приложение покажет для вашего аккаунта.
4. Выберите предложение и проверьте цену, период оплаты и условия продления на экране Google Play. Подтверждайте покупку, только если хотите оформить подписку.
